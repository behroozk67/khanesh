## ساختارهای تازه در `adapter.js`

- **`UNIT_GATED_ALIASES`**: `{ zn, cu, se } → { key, unitOk(unit) }`. فقط وقتی `NAME_MAP` کلید را نشناسد
  خوانده می‌شود. بی‌واحد یا با واحدِ ناسازگار → `unmapped`.
- **`QUAL_NO_READER`**: `Set(["ANTI_IF", "APCA"])`. ردیفِ کیفیِ این کلیدها به `noRef` می‌رود، نه
  `qual`. وقتی قاعدهٔ `P49` تأیید شد، کلید از این مجموعه خارج می‌شود.

## تغییرِ یافتهٔ موجود: `macrocytic_anemia`

- `match` بی‌تغییر است، فقط در ثابتِ `macrocyticMatch` بیرون کشیده می‌شود. شناسه و فوریت هم عوض نمی‌شوند.
- `must_say`: جملهٔ «اغلب از کمبود B12 یا فولات» با دو بندِ سه‌حالته کامل می‌شود:
  - فولات: پایین (با عدد) / طبیعی («پس کمبودِ فولات علتِ محتمل‌تر نیست») / اندازه‌گیری‌نشده.
  - B12: پایین / مرزی / طبیعی / اندازه‌گیری‌نشده.
- `suggest`: «ویتامین B12» و «فولات» فقط وقتی روی برگه نیستند. `alreadyMeasured` این کار را خودش
  می‌کند؛ بررسی می‌شود که هر دو در `SUGGEST_TESTS` هستند.
