# Contract: خروجیِ موتور و پاسخِ API برای ردیف‌های بی‌واحد

## `_engine.unitConversions[]` (موجود — یک فیلدِ اختیاری اضافه می‌شود)

```
{ test, name, raw, from, value, to,
  basis?: "printed" | "reference" | "magnitude" }   // تازه؛ نبودنش = "printed" (پاسخِ سرورِ قدیمی)
```

- `name` همان `faName(test)` است (امروز هم هست). `test` هرگز رندر نمی‌شود (N8).
- برای `basis: "reference"` و `"magnitude"` حتی وقتی سیستم «متعارف» تعیین شد (بدونِ تبدیلِ عددی)
  سطر ساخته می‌شود — چون خودِ «تعیینِ واحد» باید دیده شود. در آن حالت `raw === value` و `from === to`.

**جمله‌های فرانت‌اند برای `basis` (فارسی، برای بازبینی):**

| basis | جمله |
|---|---|
| `printed` | «واحد روی برگه نوشته شده بود.» |
| `reference` | «واحد روی برگه نبود؛ از محدودهٔ مرجعی که آزمایشگاه کنارِ این عدد چاپ کرده تعیین شد.» |
| `magnitude` | «واحد روی برگه نبود؛ این عدد فقط با یک واحد ممکن است، پس همان در نظر گرفته شد.» |

## یافتهٔ `unit_unknown_values` (تازه)

```
{ pattern: "unit_unknown_values",
  urgency: "routine" | "this_week",          // هرگز "emergency"
  headline, must_say, action, warnings?, suggest: [], sources: ["AMA_SI_UNITS", "LOINC"] }
```

**متن (پیش‌نویس — عیناً برای بازبینی):**

- `headline`: «واحدِ بعضی از آزمایش‌های برگهٔ شما مشخص نبود»
- `must_say` (برای هر ردیف یک تکه، سپس جملهٔ پایانی):
  - هر دو تفسیر طبیعی: «{نام} ({عدد}): واحد روی برگه خوانده نشد و این آزمایش با دو واحدِ رایج گزارش می‌شود که عددشان خیلی فرق دارد؛ برای همین دربارهٔ آن قضاوت نمی‌کنیم.»
  - یکی غیرطبیعی: همان، به‌علاوهٔ «بسته به واحد، ممکن است خارج از محدودهٔ طبیعی باشد.»
  - هر دو غیرطبیعی: همان، به‌علاوهٔ «با هر کدام از دو واحد که خوانده شود، خارج از محدودهٔ طبیعی است.»
  - پایانی: «این اعداد را با برگهٔ اصلی به پزشک نشان دهید؛ واحد معمولاً کنارِ عدد یا در ستونِ واحد چاپ می‌شود.»
- `action`: `routine` ⇐ «در نوبتِ عادی با پزشک مطرح کنید.» · `this_week` ⇐ «این هفته با پزشک مطرح کنید.»
- `warnings` (فقط اگر تروپونین در فهرست است): «اگر دردِ قفسهٔ سینه، تنگیِ نفس یا تعریقِ ناگهانی دارید، منتظر نمانید و همین حالا به اورژانس بروید.»

⚠️ هیچ جمله‌ای «بالا» یا «پایین» نمی‌گوید (جهت در ناحیهٔ مبهم معنا ندارد، R7)، و هیچ عددِ تبدیل‌شده‌ای نقل
نمی‌شود (N5) — فقط عددِ برگه.

## `_engine` — بی‌تغییر در بقیهٔ فیلدها

- ردیفِ نامعلوم در `_engine.tests[]` **نیست** (graded نشده). در `extracted_tests` هست (از OCR، بی‌تغییر).
- `ungraded` سریال نمی‌شود (مثلِ `P47`).
- `_engine.uncovered` شاملِ آن نمی‌شود (abnormal نیست).

## مسیر (`server.js`)

- برگه‌ای که *فقط* ردیفِ نامعلوم دارد: `graded.length === 0` ولی `ownedUngraded === true` ⇐ مسیرِ موتور ⇐
  `unit_unknown_values` ⇐ **نه** `buildNormalResult()` و **نه** مسیرِ قدیمِ بی‌موتور. (`T20`)
