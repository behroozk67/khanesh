### چرا Search Console از این ماشین ثبت نشد

۱. مرورگری که Hermes اجرا می‌کند **headless** است (`--headless=new`) و روی **کپیِ**
   پروفایل کار می‌کند؛ کاربر نمی‌تواند داخلش رمز بزند.
۲. لبهٔ ۱۵۵ (Chromium ۱۲۷+) کوکی‌ها را با **App-Bound Encryption** رمز می‌کند، پس
   کپیِ پروفایل کوکی‌های لاگین را از دست می‌دهد — در سشنِ زنده فقط کوکی‌های بی‌لاگین
   (`AEC/NID/OTZ`) دیده شد، نه `__Secure-1PSID`/`SAPISID`.
۳. هیچ‌کدام از پروفایل‌های محلی (Edge Default، Chrome 1/2/3) کوکیِ ورودِ گوگل
   ندارند (فقط `LSID`) ⇒ خطِ اولِ کار باید توسطِ خودِ کاربر انجام شود.

## ۱. Google Search Console — کارِ دستیِ یک‌بارهٔ کاربر

۱. `search.google.com/search-console` → **Add property** → نوعِ **Domain**
   (نه URL prefix؛ Domain کلِ زیرِ دامنه‌ها را می‌گیرد).
۲. گوگل یک رکورد `TXT` می‌دهد: `google-site-verification=...`
   → در Cloudflare: **DNS → Add record → TXT**، Name = `@`، Value = کلِ رشته.
3. چند دقیقه صبر → **Verify**.
4. **Sitemaps** → `sitemap.xml` را ثبت کن (آدرسِ کامل:
   `https://azmayarapp.ir/sitemap.xml`).
5. **URL Inspection** → برای این ۱۰ آدرس جدا `Request Indexing` بزن
   (سهمیهٔ روزانه محدود است؛ هدرش نده):

   `/`، `/tests`، `/test/cbc`، `/test/tsh`، `/test/ferritin`، `/test/vitd`،
   `/test/hba1c`، `/reference-ranges`، `/units-guide`، `/how-to-capture`

## ۲. Bing Webmaster Tools

۱. `bing.com/webmasters` → ورود → **Import from Google Search Console**
   (سریع‌ترین راه؛ همان اکانت گوگل را می‌خواند) یا وریفایِ دستی.
۲. `site:azmayarapp.ir` الان در Bing صفر است؛ پس این یکی واقعاً اثر دارد.

## ۳. IndexNow — خودکار و تکرارشدنی

کلید در `khanesh/public/<KEY>.txt` نگه داشته می‌شود تا **با هر build در `dist`
کپی و با هر استقرار روی سرور بنشیند** (`deploy/deploy.sh` پوشهٔ `web/` را
پاک و از `dist` پر می‌کند؛ پس کلید باید در `public/` باشد، نه دستی روی سرور).

```bash
cd khanesh && npm run indexnow
```

* آدرس‌ها از خودِ `sitemap.xml` زندهٔ سایت خوانده می‌شوند (نه از فایلِ محلی).
* `200/202` = پذیرفته شد. `403` = کلید هنوز verify نشده — یک دقیقه صبر و دوباره.
* مقصد: Bing، Yandex، Seznam، Naver (گوگل عضوِ IndexNow نیست).

**هر بار که مقاله/صفحهٔ جدید منتشر شد، همین دستور را بزن.**

## ۴. کارهای باقی‌ماندهٔ فنی (اثرِ بلندمدت)

1. **canonical و تایتلِ per-route.** الان همهٔ ~۳۰۰ صفحه یک `canonical` و یک
   `<title>` دارند ⇒ یا حذف می‌شوند یا گوگل تایتل را خودش از `h1` می‌سازد.
2. **prerender/SSG** برای `/tests/*`، `/test/*` و صفحه‌های ایستا، تا HTML اولیه
   متنِ واقعی داشته باشد (Bing و بقیهٔ خزنده‌ها JS اجرا نمی‌کنند).
3. **۴۰۴ واقعی** برای مسیرِ ناموجود (الان `200` با محتوای صفحهٔ اصلی = soft 404).
4. **JSON-LD** (`MedicalWebPage`/`FAQPage`) + `og:image`.
5. **محتوا و بک‌لینک:** کوئری‌های واقعی فارسی روی صفحه‌های آزمایش + لینک از
   بیرون (یوتیوب/تلگرام لاب‌میت، انجمن‌ها). بدونِ این، رنک روی «تفسیر آزمایش»
   در برابر باسینا/لاندا/هومکا واقع‌بینانه نیست.
