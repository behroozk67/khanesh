# مهارت: افزودن قانون پزشکی جدید

برای اضافه کردن هرگونه قانون تشخیصی جدید (مانند بیماری‌های کلیوی، کم‌خونی‌ها یا بیماری‌های غدد)، هوش مصنوعی باید دقیقاً این رویه را دنبال کند:

## ۱. تحلیل و طراحی (Plan)
- ابتدا درخواست بالینی را بررسی کنید.
- فاکتورهای آزمایشی دخیل (مانند MCV، PLT یا TSH) را شناسایی کنید.
- فوریت (Urgency) و شدت (Severity) مورد انتظار را تعیین کنید.

## ۲. پیاده‌سازی قانون در فایل الگوها
- وارد پوشه `khanesh-server/rules/` شوید.
- بر اساس دسته‌بندی بیماری، فایل مرتبط را پیدا کنید (مثلاً `patterns_anemia.js` برای خون یا `patterns_biochem.js` برای شیمی خون).
- ساختار استاندارد الگو را رعایت کنید:
  ```javascript
  {
    id: "شناسه_یکتای_قانون",
    match: (e) => {
      // منطق بررسی غیرطبیعی بودن مقادیر
      // استفاده از توابعی مثل levelGrade برای شدت‌ها
      return true_or_false;
    },
    build: (e) => {
      return {
        pattern: "شناسه_یکتای_قانون",
        urgency: "فوریت: routine | this_week | emergency",
        headline: "تیتر نمایشی بیمار",
        must_say: "توضیحات و تفسیر کامل",
        action: "توصیه عملی به کاربر",
        suggest: ["آزمایش ۱", "معاینه ۲"],
        warnings: [],
      };
    },
  }
  ```

## ۳. ایجاد تست رگرسیون (اجباری)
- فایل `khanesh-server/rules/engine.test.js` را باز کنید.
- یک بلاک `test(...)` بنویسید که شرایط قانون جدید را شبیه‌سازی کند (داده ورودی با `runEngine`).
- ادعا (Assertion) بنویسید تا مطمئن شوید قانون فعال شده و فوریت درست است.

## ۴. بررسی و اجرای تست‌ها
- در خط فرمان وارد پوشه `khanesh-server` شوید و دستور `npm run test` را اجرا کنید.
- تا زمانی که تمام تست‌ها کاملاً پاس نشده‌اند، تغییرات را نهایی در نظر نگیرید.
