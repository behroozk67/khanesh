# khanesh-motion — موشن‌گرافیکِ معرفیِ آزمایار

پروژهٔ **مستقل**: `package.json` و `node_modules` جدا دارد و هیچ فایلی از `khanesh/` یا
`khanesh-server/` را import نمی‌کند. هوکِ pre-commit فقط این دو پوشه را می‌پاید، پس فایل‌های
اینجا تستی را اجرا نمی‌کنند و تستی را نمی‌شکنند.

ابزار: [Remotion](https://www.remotion.dev) 4 — ویدیو با React. هر صحنه یک کامپوننت است و
هر عدد و رنگ در کد است، پس عوض کردنِ یک متن یا رنگ یعنی ویرایشِ یک خط و رندرِ دوباره.

## اجرا (ویندوز)

```bash
cd khanesh-motion
npm install
npm run studio          # پیش‌نمایشِ زنده در مرورگر؛ تایم‌لاین و صحنه‌ها را آنجا ببینید
npm run render:all      # هر دو ویدیو + پوستر + SRT در out/
```

بارِ اول Remotion یک نسخهٔ Chrome Headless دانلود می‌کند (حدود ۱۰۰ مگابایت).

## صدا — هنوز ندارد

ویدیوها **بی‌صدا با زیرنویسِ سوزانده** رندر شده‌اند؛ یعنی همان «نسخهٔ بدون نریشن» بریف، که برای
حلقهٔ صفحهٔ اصلی هم همین است. برای نسخهٔ با صدا:

1. نریشن را روی زمان‌بندیِ `CAPTIONS` در `src/brand.js` (یا فایلِ SRT) ضبط کنید.
2. فایل‌ها را در `public/` بگذارید (`voice.mp3`، `music.mp3`؛ موسیقیِ با مجوز).
3. در `src/index.jsx` بنویسید `const AUDIO = { voice: "voice.mp3", music: "music.mp3" };` و دوباره رندر کنید.
   موسیقی وقتی نریشن هست خودکار به ۱۸٪ پایین می‌آید.

اگر زمانِ جمله‌ای در ضبط فرق کرد، فقط `from`/`to` همان خط را در `CAPTIONS` عوض کنید.

## تصمیم‌هایی که گرفته شد

- **عددهای آزمایش لاتین ماندند** (مثلِ خودِ سایت در `RangeBand.jsx` و برگه‌های واقعی)؛ عددهای داخلِ
  متنِ فارسی فارسی‌اند.
- **لوگوی `logo-transparent.png` استفاده نشد.** در آن واترمارکِ کم‌رنگِ یک سایتِ تصاویرِ آماده
  (pngtree) دیده می‌شود و در ابعادِ ویدیو آشکار است؛ یعنی احتمالاً مجوزِ استفادهٔ تجاری ندارد.
  به‌جایش یک نشانِ ساده ساخته شد: حلقه + نشانگرِ نوارِ مرجع. اگر لوگوی بی‌واترمارک دارید، در
  `BrandMark` جایگزین کنید.
- **آدرسِ سایت در کد پیدا نشد**، پس آدرسی ساختگی چاپ نشده؛ `SITE_URL` را در `brand.js` پر کنید.
- همهٔ داده‌ها ساختگی‌اند («آزمایشگاهِ نمونه»، بی‌نام). فوریتِ صحنهٔ ۵ «نوبتِ عادی» است و متن‌ها
  ادعای تشخیص یا «جای پزشک» ندارند (بریف، بخشِ ممنوعیت‌ها).

فونتِ وزیرمتن با مجوزِ OFL از `khanesh/public/fonts` کپی شده (`public/fonts/OFL.txt`).
