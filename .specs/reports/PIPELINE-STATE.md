دستور بازگرداندنش داده شد. در نشست بعد باید تأیید شود.

   `VOTE:` / `SCORES:` / `CRITERIA:` پاسخ می‌دهد.

   (سرریز کانتکست). اگر اجماع نبود، حداکثر ۲ دور مناظره طبق `judge-with-debate`.
4. **فاز ۳ — استراتژی تطبیقی:**
   - رأی یکدست → SELECT_AND_POLISH

   - رأی شکسته → FULL_SYNTHESIS

5. **فاز ۴ — گیت‌ها:** ایجنت `qa` (`npm run lint` و `npm run build` در `khanesh/`،
   `npm test` در `khanesh-server/`) و ایجنت `code-reviewer` (مرز موتور، رشته‌های فارسی،
   دریفت قرارداد فرانت/بک).
